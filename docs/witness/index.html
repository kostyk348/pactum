Pactum Witness

A content notary: prove what a document was at a moment in time — with a signature, not a screenshot. Нотариус контента: доказать, чем документ был в момент T — подписью, а не скриншотом.

Send a file or a URL — get a signed receipt (SHA-256 + timestamp + ECDSA P-256) that anyone can verify offline, years later, without trusting the server. The journal is an append-only hash chain; signed checkpoints go to the hub so third parties co-witness the state. Screenshots are forgeable, web archives are centralized — this is the honest alternative. Пришлите файл или URL — получите подписанный приёмник (SHA-256 + время + ECDSA P-256), который любой проверит офлайн хоть через годы, не веря серверу на слово. Журнал — append-only хеш-цепочка, подписанные checkpoint-ы уходят в хаб: третьи стороны со-свидетельствуют состояние. Скриншоты подделываются, веб-архивы централизованы — вот честная альтернатива.

Who needs this todayКому это нужно сегодня

Journalism & researchЖурналистика и исследования

Notarize a page, a dataset or a leaked letter before publishing. When it disappears — and it will — the receipt proves you had the exact bytes, with a timestamp and a signature. Нотаризуйте страницу, датасет или письмо до публикации. Когда источник исчезнет — а он исчезнет, — приёмник докажет, что у вас были ровно эти байты, со временем и подписью.

Contracts & complianceДоговоры и комплаенс

Fix the exact form of a contract, an invoice, a specification at the moment of signing. Later disputes reduce to one command: re-hash the file, compare with the receipt. Зафиксируйте точную форму договора, сметы или спецификации в момент подписания. Спор потом сводится к одной команде: пересчитать хеш файла и сверить с приёмником.

Releases & CIРелизы и CI

Notarize artifacts at build time; audit at any time. The receipt travels next to the artifact — verification needs no network and no server, only the pinned public key. Нотаризуйте артефакты на этапе сборки, аудируйте когда угодно. Приёмник лежит рядом с артефактом — проверке не нужны ни сеть, ни сервер, только запиненный открытый ключ.

Three steps, zero trust requiredТри шага, доверие не требуется

01

NotarizeНотаризация

File or URL → the service hashes the bytes (SHA-256), appends an entry to the hash-chained journal and signs it with its P-256 key. Файл или URL → сервис считает SHA-256 байтов, дописывает запись в хеш-цепочку журнала и подписывает ключом P-256.

02

Keep the receiptХранение приёмника

The receipt carries everything needed to check it: the notary's public key, the sequence number, the previous entry's hash. It is self-contained. Приёмник несёт всё нужное для проверки: открытый ключ нотариуса, номер записи, хеш предыдущей. Он самодостаточен.

03

Verify offlineОфлайн-проверка

Recompute the canonical hash, check the signature, check journal membership — one CLI command, no server, years later. Пересчитать канонический хеш, проверить подпись и принадлежность журналу — одна команда, без сервера, хоть через годы.

What it proves — and what it doesn'tЧто доказывает — и что нет

ProvesДоказывает

That the notary with key p… saw exactly these bytes at ts, as entry seq of a chain that is still intact — and that independent checkpoint holders can confirm the chain was never rewritten. Что нотариус с ключом p… видел ровно эти байты в момент ts как запись seq цепочки, которая цела до сих пор, — и что независимые хранители checkpoint-ов подтвердят: историю не переписывали.

Doesn't proveНе доказывает

Guaranteed wall-clock time (server clocks are used — publish checkpoints often, RFC 3161 is on the roadmap); who was the first to publish; and protection against the key owner unless you pin the key and keep external checkpoints. Гарантированное астрономическое время (берутся часы сервера — публикуйте checkpoint-ы чаще, RFC 3161 в roadmap); кто опубликовал первым; и защиту от владельца ключа, если вы не запинили ключ и не храните внешние checkpoint-ы.

Start in 30 secondsЗапуск за 30 секунд

Local file, no server (CI)Локальный файл, без сервера (CI)

git clone https://github.com/kostyk348/pactum && cd pactum && cargo build --release
./target/release/pactum witness notarize contract.pdf --store --note "подписан сторонами"
./target/release/pactum witness verify receipt.json --dir witness-data

As a serviceКак сервис

pactum witness serve --dir witness-data --listen 0.0.0.0:8090
curl -X POST --data-binary @page.html "http://127.0.0.1:8090/notarize?store=1"

Docker

docker build -t pactum-witness .
docker run -p 8090:8090 -v witness-data:/data pactum-witness

Co-witness via the hubСо-свидетельствование через хаб

pactum witness serve --dir witness-data \
  --hub-url http://127.0.0.1:8080 --hub-topic witness.head --checkpoint-every 25
