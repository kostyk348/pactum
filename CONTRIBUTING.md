# Вклад в Pactum

Спасибо, что заглянули. Проект молодой, но правила простые и честные.

## Как помочь

1. **Найдена ошибка** — откройте issue: что делали, что ожидали, что вышло.
   Если есть traceback/лог — приложите.
2. **Изменение кода** — форк, ветка, PR. Один PR — одна тема.
3. **Документация** — опечатки и неясности чинятся так же через PR.

## Правила разработки

```bash
cargo test --workspace     # все тесты, включая сетевой e2e
cargo clippy --workspace --all-targets -- -D warnings   # ноль предупреждений
cargo fmt --all            # формат проверяется в CI
```

Контракты (Solidity) тестируются отдельно: `cd contracts/hardhat && npm i && npx hardhat test`.

## Что принимается хорошо

- исправления с тестом, воспроизводящим ошибку;
- честные ограничения, доведённые до фичи (тайм-ауты, отказы, валидация);
- новые `Sandbox`/`SettlementProvider`/`Deliverer`-бэкенды — швы уже готовы;
- примеры и сценарии (`examples/`), особенно не-агентские.

## Что не принимается

- магия вместо честности: молчаливые повторы, тихие потери, скрытые дефолты;
- ломающие изменения форматов (письма, реестр proof, контракт) без RFC-issue
  и бампа версии протокола;
- зависимости «на всякий случай» — стек и так тяжёлый, tokio+axum достаточно.

## Лицензия

Внося изменения, вы соглашаетесь, что они распространяются под Apache-2.0.
